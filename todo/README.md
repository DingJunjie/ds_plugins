# 待办清单 · Todo

一个单文件、离线可用的待办清单。双击 `index.html` 用浏览器打开即可，无需安装、无需联网。

<img src="preview-light.png" width="420" alt="浅色主题"> <img src="preview-dark.png" width="420" alt="深色主题">

## 功能

- 添加 / 编辑（双击文字或点铅笔）/ 删除 / 勾选完成
- 优先级（高 · 中 · 低）与截止日期，逾期会变红提示
- 一键切换深色 / 浅色主题，记得上次的选择
- 全部 / 进行中 / 已完成 三种视图，顶部圆环显示完成进度
- 拖拽排序（「全部」视图下）
- 数据存在浏览器 `localStorage`，关掉页面也不会丢
- **导出 Markdown**：下载 `todo-YYYY-MM-DD.md`，也可一键复制到剪贴板

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `/` | 聚焦输入框 |
| `Enter` | 添加（在输入框里） |
| `⌘ / Ctrl` + `Enter` | 在页面任意位置添加 |
| `Esc` | 取消输入 / 退出编辑 |

## 导出的 Markdown 长什么样

```markdown
# 待办清单

> 导出时间：2026-11-09 10:56　·　完成 2/5（40%）

## 进行中

- [ ] 把今天的三个重点写下来 · **高** · 截止 2026-11-09
- [ ] 出门走 20 分钟，晒晒太阳 · **低**

## 已完成

- [x] 喝一杯温水，深呼吸三次 · **低**
```

标准的 `- [ ]` 任务列表语法，可直接粘进 Obsidian、Notion、GitHub Issue 或任意 Markdown 编辑器。

## 小提示

- 第一次打开会带 4 条示例待办，直接删掉或勾掉即可。
- 想清空重来：清掉站点的本地存储，或删掉全部条目。
- 深色模式也可以用 `index.html?theme=dark` 直接打开。
