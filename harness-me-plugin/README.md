# Me · 留给自己的空间

独立 DSH 插件，适配 DSH **0.2.2-rc.1**。不修改条目与 todo 插件。

## 首版

- 一句话保存，支持实际发生时间、分类、标签、敏感标记；按天时间线、关键词/日期筛选、编辑删除。
- 关于我卡片：来源、记录/确认日期、有效/过时/未知状态、是否允许纳入跨会话摘要。
- 主会话工具按需读取背景、查询/保存原始记录。读取规则通过插件正式 systemPrompt section 注入新会话，不注入个人历史。
- 筛选范围 Markdown 导出、完整 JSON 备份、预览后导入。同 ID 相同内容跳过，同 ID 不同内容整次拒绝，不静默覆盖。
- 本地保存不依赖 AI。错误保留输入、revision 防覆盖、原子写入、损坏文件报错而不清空。

## 已获用户授权的写入边界

明确本人日常事实报告可以自动保存；示例、假设、他人经历和 AI 方案不保存。健康、用药、心理等敏感资料仍须用户明确要求保存。用户在聊天里说“更新 Me 信息／目标……”即可修改基础背景和目标，无需逐项填写页面；聊天中的性格/MBTI 观察只能有明确依据、标为暂定且可更正，不能当测评结论。用户主动要求分析或点击非敏感文字的“记录并 AI 整理”时，会发送相关文字给当前模型供应商；不上传图片。

这是模型工具使用规则，不是语义事实校验器：工具无法从一句文本可靠判断它是否为真实用户经历。模型应遵循工具说明，用户可以在页面检查、更正、删除。

## 数据与隐私

工作数据：`~/.dsh/me/me.json`（与安装包分开，更新安装不覆盖数据）。只存本地明文，不加密；文件/目录采用仅当前用户访问权限。插件通过当前模型服务做用户主动触发的单条文字整理；经聊天工具读取的文字也可能进入当前模型上下文及聊天日志。敏感记录不通过悬浮窗自动送模型。

JSON 备份包含全部原始记录、个人背景、每日事项和敏感内容。请妥善保管；Markdown 是阅读输出，不可用来恢复。导入仅合并，不传播删除。坚果云功能只有用户点击才执行，不是自动双向同步，也不修改原来的全局同步按钮。外部备份、聊天日志、系统/公司备份不会随页面删除自动清除，不能承诺抹除痕迹。

若文件损坏，插件拒绝读取/写入。先保留损坏文件副本，再通过已验证 JSON 备份恢复；不要把损坏文件当空白重置。写锁异常会明确报错，不自动抢锁覆盖。

## 使用

刷新现有 DSH 页面，侧栏打开 **Me**。先试一句自己的记录，例如在聊天中说“记一下……”（文档示例不会预先写入）。补记时明确发生日期，页面区分发生时间与记录时间。

新会话可说：“结合 Me 里最近与睡眠相关的记录，看看有哪些值得继续观察的变化。”助手应先调用 `me_context`，需要时再查询原文并引用来源 ID。工具可用和规则已注入不等于每个模型绝对遵守，仍需真实新会话验收。

## 开发

```sh
pnpm install --ignore-scripts
node build.mjs
node --test test/*.test.mjs
```

通过 DSH 插件管理器安装本目录。构建页面资源后，重新安装/加载插件并刷新原 DSH URL；不需要启动替代 Web 服务。

## v0.2–0.3：概览、悬浮记录、每日事项与统计

- Me 首页按基础信息、性格、MBTI、目标、其他分组展示有来源的背景卡。聊天里说“更新我的 Me 信息／目标……”即可保存；自述与测评标来源，聊天中观察到的倾向标 **AI 观察·暂定**，有证据且可更正；不诊断、不凭讨论话题认定人格。
- 最近 14 天真实记录图表：饮水记录次数、**明确毫升数**、运动分钟、体重公斤、睡眠小时。无记录留白而非零。图表仅统计有可核对单位的指标；旧记录不自动臆测数值。
- 侧栏 Me 菜单右侧的独立开关可打开/关闭悬浮窗。悬浮窗可拖动，位置只保存在本机浏览器；个人输入草稿不写入 localStorage。回车后先展示整理预览，**取消不保存，确认后才写入一次**。AI 整理默认开启，可在 Me 的数据与隐私设置关闭；AI 不可用时仍能确认保存原文。只发送当前这一条文字，不发送全部历史；不要在悬浮窗输入敏感资料，敏感记录可在时间线明确标记后仅本地保存。
- 操作栏使用圆形图标：水滴一键记一次饮水（不猜毫升数）、哑铃选择并记录运动分钟、图表查看已有身体记录、清单查看和勾选今日 Me 日常。身体面板只汇总记录，不作健康诊断。60 分钟未有**饮水记录**时边框变深蓝并有轻微 box-shadow；120 分钟未有**走动/运动记录**时变红，红色优先。可点走动图标记录一次起身走动，不凭空记录分钟数。两种提示可在 Me 设置分别关闭；默认启用，仅 DSH 页面运行时生效，不监测实际身体活动，无声音、无震动。计时从本次启用或最后有效记录（较晚者）开始。
- “今日 Me 日常”是 Me 独立维护的 recurring daily items，可在 Me 页面添加、编辑、删除，在页面或悬浮窗按日期完成/撤销；不修改 todo 插件，也不把未完成日期当成失败。聊天新增个人事项仍遵循正式待办提案确认流程，不直接调用页面接口绕过确认。
- 旧版 v1 JSON 仍可读和导入；新指标、背景元数据与 Me 每日事项随完整 JSON 备份和恢复。无自动网盘同步。

## v0.5：形体项目

Me 内新增独立“形体”Tab，分为减脂、护肤、穿搭、体态、其他；每项区分当前资料、目标和实际执行记录。聊天工具支持 `me_appearance_get`；形体执行记录通过 `project: appearance` 归类，原始记录仍保留在 Me 时间线。

## v0.4：坚果云手动备份与恢复

- 在“数据与隐私”中点击“备份到坚果云”，才会把完整 JSON 写入 `~/Nutstore Files/Nutstore/DeepSeekHarness/Me/backups/`。每次使用独立时间戳和随机 ID 文件名，不覆盖旧备份；可用 `DSH_ME_NUTSTORE_DIR` 指定其他本地同步目录。
- 备份是**明文 JSON**，含敏感资料；新文件权限为仅当前用户可读写。插件不调用坚果云网络 API，实际上传由坚果云客户端处理。“已写入目录”不等于“云端上传完成”，上传状态请在坚果云客户端确认。
- “从坚果云恢复”列出最多 50 个近期备份，选择后先预览数量、版本和同 ID 项，再由用户确认合并。完全相同项跳过；同 ID 不同内容整次拒绝；不覆盖本地记录，不传播删除。revision 冲突时重新预览。
- 没有自动上传、自动拉取、后台同步或跨设备冲突解决。删除旧备份需在同步目录中手动进行，页面不会擅自清理。

## v0.6：复盘

- Me 内新增“复盘”Tab，可按实际日期保存原始日记和独立复盘分析；聊天中可使用 `me_review_list/get/save/delete`，以及 `me_review_export` 导出 Markdown。
- 原始用户叙述、AI/手动分析、分析来源、依据记录 ID、确认状态和敏感标记分开保存；修改原始叙述会清除旧分析并回到草稿，避免把过时解释当最新事实。
- 敏感复盘默认不被聊天读取；页面可明确查看和维护本地内容。没有自动后台分析，也不会把建议写成已发生的事实。
- 复盘支持日期筛选、编辑、删除、Markdown 导出和 JSON 备份恢复；旧版 v1 备份继续兼容。
